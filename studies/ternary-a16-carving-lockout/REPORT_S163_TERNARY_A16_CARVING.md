## Honest Limits

- The carving model is a cleared abstraction of `Gates.step` (gradient move `u`, pressure move `p >= 0`, clip at `0`); Adam moment state and the `ln 20` slope constant are not modeled. The lockout argument needs only that a zeroed/removed gate receives no gradient (`fresh = False` once dropped from `kept`) and nonnegative pressure.
- Rollback ordering differs in scope between the two layers: the Lean `rollback` models only the length → `D^2` check-before-assign contract (unpack rejects any length other than `16`, then the norm is checked before assignment); the Python verifier enforces length → SHA-256 digest → `D^2`. The SHA-256 digest step is checked in Python only and is not modeled in Lean.
- The `-1` state is a scale sign-flip on unchanged nibbles; its `c XOR 0xFFFF` description holds in the bipolar sign-code view (Pillar 1), not as a rewrite of the stored nibble bytes.
- The 193/671/184/141/35/33 counts are the paper's reported values, carried as exact witnesses; the `193/193` simulations reproduce the mechanism, not the paper's training runs.
- `N0` novelty default from the preregistration is unchanged; no prior-art audit was performed here.
