At 3.0 bits on SmolLM2, A32 scores 0.358845 and A16 0.380994 against 0.419643 for integer levels; A16 is the lowest arm on Qwen2.5 (0.160368). The packed A16 file is the same 18 bytes per 32 weights as the Z^32 file, read back bit for bit, 0.83 dB lower weight error, and 4.6–12.7 errors lower with no columns kept; it decodes 2.5–3.0x slower on one core (9.4–10.1M weights/s). The 128-weight ball with a 16-bit scale stays 3.1–6.7 errors lower still.

Live RTX 3080 (sm_86) studies merged the same day: 3B scale law with the opposite-sign A16 law returning (#86), A16_BlockH4 #1 on 3B Python (#90), 592.31 Gw/s zero-spill PTX kernel (#91), global-sort cannibalization falsified with a coupled-coherent cure (#93), and the stratified quad-snake 3B record 0.023154 / 0.020494 (#95), plus a 0.5B full-model engine at 400.58 tok/s and 4.91x lower energy (#88) and three pure-Init Lean 4.36.0 theory studies (#87, #92, #94).

Limits

  • Real-weight KL is measured on wikitext-2 test text only, with no calibration data. Other kinds of text are not yet tested for PR #41 arms.
  • A packed A16 file (hampack) now exists and is read back bit for bit, but it decodes 2.5–3.0x slower than the Z^32 file on one core. No packed format exists yet for the turned E8 lattice; its bit counts are counted, not stored.
  • Roofline figures are bandwidth ceilings. RTX 3080 sm_86 kernels are now measured (up to 592.31 Gw/s fused gather, 213.48 tok/s projected on the 3B down_proj); TPU v5e / Pallas remain unmeasured.
  • On CPU, every E8 arm is far slower than the Q4_K_M baseline. The records state this and do not claim otherwise.
