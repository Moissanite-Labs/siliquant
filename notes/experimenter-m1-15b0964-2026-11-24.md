## Runner changes made for the Q8_0 stratum (all on `exp/gemma-a16-port`, PR #97)

1. `360c9ed` — `--stream-arms`: workers write each rounded matrix to a `.npy` sidecar and
   the parent assembles the GGUF via `write_copy_streaming`, loading one tensor at a time.
   Byte-identical to `write_copy` (SHA-256 parity test). Needed because ball arms replace
   all 25.6B block weights with float16: the default path would hold ~51 GB of
   replacements in the parent on a 64 GB host; each ball-arm GGUF is ~52.7 GB.
2. `15b0964` — `ensure_baseline_gguf` passes `--allow-requantize` when any source tensor is
   quantized (llama-quantize refuses Q8_0→Q4_0 otherwise; the first sweep hit exactly
   that), and cached GGUFs (baselines/imatrix) are trusted only if they start with the
   GGUF magic; zero-header partials from killed runs are deleted and rebuilt.
3. `26627b6` — `.kld` caches are trusted by non-empty size, not GGUF magic (kld files
   start with `_log`).
4. `1f59f3a` — `_drop_file_cache` (posix_fadvise DONTNEED) on the source model after each
   streamed arm write, before scoring, so its ~29 GB of page cache does not crowd out the
   Metal mapping of the ~53 GB arm.

## Observations worth noting (2026-11-24, mid-run)

1. **ngl placement shifts Metal numerics by ~0.001–0.003 KL at 27B** (free measurement from
   the discarded stock rows, same arm files re-scored): `file:Q4_K_M-imat` wikitext KL is
   `0.031320` at ngl 999, `0.032235` at ngl 40, `0.034581` at ngl 20; `file:Q4_K_M` wikitext
   `0.055948 / 0.056413 / 0.058552`. So (a) the uniform-ngl stratum decision was necessary —
   mixing backends would add a noise floor of this size, and (b) cross-stratum comparisons
   (this Q8_0 stratum vs the BF16 4B/12B rows at ngl 999) carry a ~0.001–0.003 ngl noise floor
   on stock arms; interpret 1e verdicts against within-stratum (ngl 20) numbers primarily.
2. **The Q8_0 stratum compresses KL**: matched `file:Q4_K_M-imat` wikitext KL ≈ 0.0346 at 27B
   (ngl 20) vs 0.0488 at 12B BF16 stratum — quantizing from an already-Q8_0 reference starts
   closer, so absolute KL is not comparable across strata; iso-KL **block savings** vs the
   stratum's own stock remains the comparable metric. Reference strength: Q8_0 27B wikitext
   PPL(base) ≈ 7.97 (12B BF16 was 8.65; 4B 15.33).
3. **Stock bpw at 27B is 4.8060** — the same "normal band" as 12B (4.8076), so no fallback
   promotion at this scale; `b_stock = 4.8060` for the 1e bracket rule.
4. **Operational**: 28.7 GB `hf download` ≈ 12 min, LFS oid == file SHA-256 (verified by
   re-hash). Ball-arm build ≈ 22 min/arm at `--workers 8 --stream-arms`, arm write ≈ 25 s
   (52.7 GB), scoring at ngl 20 ≈ 2.5–26 min/row by text. Runner gotchas hit and fixed this
   session (all pushed): Q8_0 sources need `--allow-requantize`; trust cached GGUFs only with
   the GGUF magic (killed runs leave zero-header partials); `.kld` caches start with `_log`,
   trust by size; drop the source model's page cache (`posix_fadvise DONTNEED`) before scoring
   a 52.7 GB arm or Metal OOMs.
